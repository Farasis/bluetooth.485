# 蓝牙 ⇄ RS485 解析传输软件

一个运行在浏览器里的 **BLE 与 RS485 双向透传 + Modbus RTU 解析**工具。零构建、零依赖的纯 HTML/JS 单页应用。

- **发送方向**：485 数据 → 蓝牙（转发到蓝牙设备）
- **接收方向**：蓝牙数据 → 485（转发回串口/485 总线）
- **解析**：收发数据按帧显示十六进制 + ASCII，内置 **Modbus RTU** 帧解码（CRC16 校验、功能码字段、异常响应）
- **无硬件可用**：内置「模拟对端 (Echo)」+「模拟串口」，开箱即可端到端验证完整链路

## 快速开始

Web Bluetooth 与 Web Serial 都要求**安全上下文**（`localhost` 或 HTTPS）。用本地静态服务器打开：

```bash
cd d:\APP\bluetooth
python -m http.server 8000
```

浏览器打开 **http://localhost:8000**（推荐 Chrome / Edge 桌面版）。

> 注意：`http://<局域网IP>:8000` **不是**安全上下文，Web Bluetooth 会拒绝访问。请始终用 `localhost`。

## 无需硬件，30 秒跑通

1. 打开页面，默认「模拟串口」已启动，周期发送测试帧 `01 03 00 00 00 01 84 0A`
2. 勾选「蓝牙」卡里的 **模拟对端 (Echo)**
3. 点击 **扫描 / 连接** → 状态变为「已连接（模拟对端）」
4. 观察下方日志：**发送** 与 **接收** 两行相同十六进制交替出现，均解析为 Modbus 帧且 **CRC 校验通过**

此时数据流为：模拟串口 → 桥 → 模拟蓝牙 → 原样回显 → 桥 → 日志/解析。

## 连接真实设备

### 蓝牙（BLE 从机，Nordic UART Service）

1. 取消勾选「模拟对端」
2. 点击 **扫描 / 连接** → 浏览器弹出系统蓝牙选择框（仅显示广播 NUS 服务的设备）
3. 选中你的透传模块（HM-10、JDY-08 等，或任何实现 NUS 的串口桥接设备）
4. 连接成功后，数据开始双向透传

常用参数（蓝牙卡内可调）：

| 参数 | 说明 | 默认 |
|---|---|---|
| 写包大小 | BLE 单包写入字节数（默认 MTU 安全值 20，可到 512） | 20 |
| 分包间隔 | 分包写入间的延时 ms，WriteWithoutResponse 时是唯一背压手段 | 5 |

NUS 服务定义：
- 服务：`6e400001-b5a3-f393-e0a9-e50e24dcca9e`
- 发送（app → 设备）：RX 特征 `6e400002-b5a3-f393-e0a9-e50e24dcca9e`
- 接收（设备 → app）：TX 特征 `6e400003-b5a3-f393-e0a9-e50e24dcca9e`

### 485 串口（USB 转 485 适配器，Web Serial）

1. 将 485 侧模式切换为 **真实 (Web Serial)**
2. 选择波特率（默认 9600，8N1 无流控）
3. 点击 **选择并打开串口** → 选择 USB 转 485 的 COM 口
4. 数据开始双向透传；断开后自动回到模拟模式

## 功能说明

- **转发开关**（桥接条）：`串口→蓝牙` / `蓝牙→串口` 各自独立开关
- **帧空闲超时**：字节流停顿超过该时长即判定为一帧，用于日志分组与解析
- **日志**：
  - 发送（TX，蓝色）与接收（RX，绿色）分色显示，每帧带时间戳
  - 每帧下方自动显示 Modbus 解析结果（绿 = CRC 通过，红 = 异常/校验失败，灰 = 无法识别）
  - 显示过滤、自动滚动、暂停/继续、清空
- **自检**：点击「自检」在日志区运行 9 项无硬件测试（CRC、请求/响应/异常解析、坏 CRC、拼接流、端到端环回、方向门控）

## Modbus RTU 解析支持

- CRC16-Modbus（多项式 0xA001，小端传输）校验
- 功能码：`01 读线圈`、`02 读离散输入`、`03 读保持寄存器`、`04 读输入寄存器`、`05 写单个线圈`、`06 写单个寄存器`、`0F 写多个线圈`、`10 写多个寄存器`、`16 掩码写寄存器`、`17 读写多寄存器`
- 异常响应（功能码 + 0x80）：异常码中文说明
- 支持请求 + 响应拼接成同一帧（485 半双工快速应答）与错位重同步

| Web Bluetooth | ✅ | ✅ | ❌ | ❌ |

## 文件结构

```
index.html      布局与界面
style.css       深色主题
js\main.js      控制器：接线、日志渲染、自检
js\ble.js       BLEClient（真实 NUS）+ SimBLEClient（模拟对端）
js\serial.js    SimSerialPort（模拟）+ WebSerialPort（Web Serial）
js\bridge.js    双向转发 + 按空闲超时组帧
js\modbus.js    CRC16 + Modbus RTU 解析
js\utils.js     hex/ascii/时间戳工具
```
